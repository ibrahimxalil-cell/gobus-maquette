# GoBus — Application installable

GoBus peut maintenant être utilisé comme une **application installable sur iPhone, iPad et Android** grâce à une PWA (application web progressive).

## Activer l'application en ligne

1. Ouvrez les paramètres du dépôt GitHub : **Settings**.
2. Cliquez sur **Pages**.
3. Sous **Build and deployment**, choisissez la branche **main** et le dossier **/(root)**.
4. Cliquez sur **Save**.
5. Attendez quelques minutes.

GitHub donnera une adresse publique semblable à :

`https://ibrahimxalil-cell.github.io/gobus-maquette/`

## Installer sur iPhone ou iPad

1. Ouvrez l'adresse dans **Safari**.
2. Appuyez sur le bouton **Partager**.
3. Sélectionnez **Sur l'écran d'accueil**.

## Installer sur Android

1. Ouvrez l'adresse dans **Chrome**.
2. Appuyez sur les trois points.
3. Sélectionnez **Installer l'application** ou **Ajouter à l'écran d'accueil**.

## Important

Cette PWA fonctionne hors connexion après sa première ouverture grâce au service worker. La localisation du bus, les comptes, le pointage réel et les notifications à distance sont encore des simulations : ils nécessiteront une base de données et un serveur.
